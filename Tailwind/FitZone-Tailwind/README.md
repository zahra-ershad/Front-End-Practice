# FitZone – Gym & Fitness Landing Page 🏋️
- A modern, fully responsive gym landing page built with **Tailwind CSS** and **vanilla JavaScript**.

FitZone is a single-page landing site for a fitness gym. It features a fixed navigation bar with a mobile hamburger menu, a hero section with a background overlay, service highlights, alternating showcase sections, client testimonials, and a contact footer.

## ✨ Key Features

- ✅ **Fully responsive** – mobile-first design with Tailwind breakpoints  
- ✅ **Fixed navigation bar** with mobile hamburger menu (vanilla JS)  
- ✅ **Hero section** with background image, overlay, and CTA buttons  
- ✅ **Service highlights** – 3 icon cards (Expert Trainers, 24/7 Access, Track Progress)  
- ✅ **Alternating showcase sections** – image + text, responsive grid  
- ✅ **Testimonials** – 3 client cards with avatars  
- ✅ **Footer** with address, phone, and social icons  
- ✅ **Custom color palette** – orange (#f97316) as primary accent  
- ✅ **Google Fonts** – Montserrat (300, 500, 900)
