## Description
-This landing page is designed for a fictional actress portfolio. It features a fixed navigation bar, a hero section with a call‑to‑action, a photo gallery, a contact section, and a footer. The design is elegant, minimal, and fully responsive 🎭👱🏻‍♀️.


## 🟢Topic Used:
| Concept | Implementation |
|---------|----------------|
| **Flexbox** | Navbar, hero section, photo gallery, footer layout |
| **Position: fixed** | Sticky navigation bar |
| **@font-face** | Custom `Lora` font |
| **CSS Variables** | `:root` for color theming |
| **Flex-wrap** | Responsive gallery wrapping |
| **Flex-basis** | Column width control in hero section |
| **Object-fit: cover** | Image cropping and sizing |
| **Hover effects** | `:hover` on buttons, icons, and images |
| **Transition** | Smooth hover interactions (`transition: all 0.3s ease`) |
| **Keyframe animation** | Footer SVG icon bounce (`@keyframes footer-svg-move`) |
| **Media Queries** | 4 breakpoints for mobile, tablet, and desktop |
| **SVG icons** | Inline SVGs for social media |
